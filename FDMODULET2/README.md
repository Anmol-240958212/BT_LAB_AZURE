# Fixed Deposit service

This Spring Boot service owns FD accounts, transactions, interest processing, maturity and premature withdrawal, notifications, and reporting. It runs on port `8081` and communicates with Auth and Product & Pricing through Kafka.

Use the repository-level [startup guide](../startup.md) to run the complete platform and [Kafka guide](../KAFKA_SETUP.md) for topic and troubleshooting information.
